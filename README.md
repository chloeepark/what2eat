# 🍽️ what2eat

**what2eat** is a simple web application that helps users decide what to eat by providing random food suggestions. Built with HTML, CSS, and vanilla JavaScript, it's a lightweight, responsive app that solves the age-old question: *"What should I eat today?"*

## 🔍 Features

- Random food suggestion generator
- Clean and intuitive user interface
- Responsive design that works on desktop and mobile devices
